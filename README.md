# Sae's Undercutter (distribution)

This is a plugin **distribution** repo, not the source — it holds only the compiled plugin package (`latest.zip`) and the repo manifest Dalamud's plugin installer reads (`pluginmaster.json`).

Sae's Undercutter checks your retainers' market board listings for undercuts and walks you through repricing them — one retainer or all of them — always waiting for you to Confirm each price.

## Installing

1. In game, open Dalamud Settings → Experimental → Custom Plugin Repositories.
2. Add this URL, tick the box, and save:

   ```
   https://raw.githubusercontent.com/Jeddx7/SaesUndercutter-Repo/main/pluginmaster.json
   ```

3. Open the plugin installer (`/xlplugins`), search for **Sae's Undercutter**, and install it.

Type `/saeuc` in game to open it. Updates arrive through the plugin installer automatically.
